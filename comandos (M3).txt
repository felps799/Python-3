🔎 Aula 16: Tuplas
As tuplas são as variáveis compostas mais básicas do Python. 
Elas permitem guardar múltiplos valores em uma única estrutura na memória usando índices numéricos sequenciais iniciados em 0.
Sintaxe de Declaração: 
    São estruturadas nativamente entre parênteses () com os elementos divididos por vírgulas.
    Regra de Imutabilidade: Tuplas são imutáveis. 
    Não é permitido alterar, incluir ou apagar componentes internos enquanto o programa roda.
    
    Acesso e Fatiamento ([:]): Os colchetes [] chamam posições específicas. 
    Posições negativas leem de trás para frente. 
    No fatiamento, o elemento final estipulado é sempre desconsiderado pelo interpretador.
    
    Soma de Tuplas (+): Concatena as duas variáveis em uma nova tupla, mantendo rigorosamente a ordem da operação.
    
    Funções Úteis: 
        len() retorna a quantidade total de valores; 
        sorted() mostra os elementos em ordem alfabética ou numérica em formato de lista; 
        .count() conta ocorrências de um item;
        .index() localiza a primeira posição de um dado.

    Deleção Estrita: Não é possível apagar dados isolados, mas o comando del(tupla) remove a estrutura inteira do sistema.

🔎 Aula 17: Listas (Parte 1)
As listas preenchem a necessidade de trabalhar com grupos dinâmicos de dados que precisam ser constantemente atualizados no código.
Sintaxe de Declaração: 
    São estruturadas nativamente utilizando colchetes [].
    Regra de Mutabilidade: Listas são mutáveis. 
    É possível alterar qualquer elemento interno diretamente mapeando seu índice correspondente.
    
    Inclusão de Dados:
        .append(valor): Adiciona um dado diretamente na última posição da lista.
        .insert(índice, valor): Insere um dado em uma posição cirúrgica, empurrando os elementos posteriores e recontando as chaves automaticamente.

    Exclusão de Dados:
        del lista[índice]: Deleta o elemento com base na numeração de sua posição.
        .pop(índice): Remove pelo índice. 
            Quando executado vazio, remove o último elemento da lista.
        .remove(valor): Localiza e remove o dado baseado no seu conteúdo escrito, eliminando apenas a primeira ocorrência encontrada.
        
    Tratamento de Erros: Tentar remover valores inexistentes trava o script. 
        Usa-se if valor in lista: para validar a presença do item antes da exclusão.
    
    Organização Avançada: 
        .sort() organiza dados em ordem crescente; 
        .sort(reverse=True) organiza em ordem decrescente.
    
    Ligação vs. Cópia: 
        Atribuir uma lista a outra gera um vínculo de memória (mudar B altera A). 
        Para duplicar a lista sem conexão, usa-se fatiamento completo: B = A[:].

🔎 Aula 18: Listas (Parte 2)
Foca no conceito de estruturas multidimensionais, conhecidas popularmente como matrizes ou listas compostas (listas colocadas de forma aninhada dentro de outras listas).

    Inserção Estruturada: 
        É possível usar o comando .append() para inserir uma lista inteira dentro de outra.
    
    Cópia de Segurança Aninhada: 
        Ao inserir uma sublista dinamicamente em loops, deve-se gerar uma cópia com fatiamento antes de limpar a lista temporária com .clear(). 
        Esquecer o fatiamento vincula as estruturas e cria itens vazios na lista principal.
        
    Declaração Unificada: 
        É possível instanciar sublistas em lote separando-as por vírgula dentro do colchete principal.
    
    Indexação Dupla: 
        Para ler um dado pontual na estrutura composta, utilizam-se dois colchetes em sequência. 
        O primeiro localiza a sublista interna; o segundo seleciona o valor dentro dela.
        Exibir apenas a lista principal com um único colchete trará a sublista completa correspondente àquela posição.

🔎 Aula 19: Dicionários
Os dicionários quebram a barreira dos índices exclusivamente numéricos, permitindo criar chaves literais customizadas para mapear os dados.
    Sintaxe de Declaração: 
        São estruturados nativamente utilizando chaves {} ou a função dict().   
        Os dados são mapeados na relação chave: valor.
        
        Acesso por Chaves: 
            Substitui-se o índice numérico pelo nome literal da chave.
        String Formatada: 
            Se o dicionário estiver dentro de um print(f"...") com aspas duplas por fora, a chave inserida obrigatoriamente deve utilizar aspas simples para evitar conflitos de interpretação sintática.
        
        Adicionar Elementos Dinâmicos: 
            Dicionários não aceitam o método .append(). 
            Para incluir uma nova chave com valor, basta fazer uma atribuição direta. 
            Se a chave já existir, o valor é apenas atualizado.
        
        Remover Elementos: 
            Utiliza-se o comando del dados['chave'] para eliminar uma propriedade específica e seu respectivo valor.
        
        Estrutura de Elementos Internos:
            .keys(): Retorna o grupo mapeado de chaves.
            .values(): Retorna o grupo mapeado de valores puros de dentro da estrutura.
            .items(): Retorna a coleção completa contendo chaves e valores agrupados em pequenas tuplas dentro de uma grande lista.
            
        Laços de Repetição (for): 
            Substitui-se a função tradicional enumerate() pelo método .items() para iterar sobre chaves e valores simultaneamente.
        
        Cópia de Dicionários: 
            Dicionários também criam vínculos de memória se forem igualados diretamente. 
            Como não possuem suporte ao fatiamento por colchetes, deve-se utilizar obrigatoriamente o método nativo .copy() para clonar a estrutura de maneira isolada.

🔎 Aula 20 e 21: Funções 
As funções (ou rotinas) são trechos de código personalizados que realizam tarefas específicas e podem ser executados em momentos diferentes do programa principal. Elas servem para otimizar o desenvolvimento, eliminando códigos repetitivos e cansativos por meio da criação de comandos customizados.

    Sintaxe de Declaração (def): 
    Uma função personalizada é declarada utilizando a palavra-chave def, seguida pelo nome da função, parênteses () e dois pontos : . 
    Todo o bloco de código que pertence à rotina deve estar deslocado para dentro por meio da indentação.
    
    Organização Estética (PEP 8): 
    O interpretador do Python e ambientes de desenvolvimento exigem que haja exatamente duas linhas vazias de espaçamento entre a definição de uma função e o início do programa principal (ou de outra função) para manter o código visualmente limpo e organizado.
    
    Mecanismo de Execução: 
    O interpretador lê as definições criadas pelo def, mas não executa o conteúdo interno delas de forma automática. 
    O bloco interno só é ativado quando a função é explicitamente chamada pelo seu nome seguido por parênteses no programa principal. 
    Nesse momento, o fluxo do script é desviado para a função e retorna para a linha subsequente assim que a rotina termina.
    
    Parâmetros Formais: 
    São as variáveis declaradas dentro dos parênteses na definição da função (def nome(parametro):). 
    Eles funcionam como contêineres que se adaptam e recebem os dados enviados de fora.
    
    Parâmetros Reais (Argumentos): 
    São os valores literais ou variáveis enviados de fato na linha de chamada da função. 
    Por padrão, o primeiro valor enviado preenche o primeiro parâmetro, e o segundo preenche o segundo. 
    No entanto, é possível quebrar a ordem física nomeando explicitamente as atribuições na chamada 
    (ex: soma(b=5, a=4)).
    
    Empacotamento de Parâmetros (*): 
    Quando não se sabe a quantidade exata de valores que o usuário enviará, utiliza-se um asterisco * antes do nome do parâmetro na declaração (ex: def contador(*num):). 
    O Python recebe todos esses argumentos dinâmicos e os empacota nativamente no formato de uma tupla imutável.
    
    Passagem por Referência: 
    Ao passar estruturas compostas mutáveis (como listas) como parâmetro direto para uma função, o Python realiza uma passagem por referência em vez de copiar os valores. 
    Isso significa que qualquer alteração ou manipulação feita nos elementos da lista dentro da função modificará diretamente a lista original localizada no programa principal.
    
    Ajuda Interativa (help()): 
    O Python possui um sistema nativo de suporte chamado Interactive Help. 
    Ao executar a função embutida help() passando o nome de qualquer comando, função ou biblioteca como argumento (ex: help(print)), o sistema exibe o manual de instruções e a descrição detalhada de uso daquela ferramenta.
    
    Documentação Customizada (Docstrings): 
    Para que as suas próprias funções gerem manuais legíveis no help(), utiliza-se uma docstring (1:09). Ela consiste em inserir uma string literal aberta e fechada por três aspas duplas """ exatamente na primeira linha logo abaixo do comando def. 
    Todo o texto explicativo ali digitado passa a compor o atributo especial __doc__ daquela função.
    
    Argumentos Opcionais: 
    É possível definir valores padrão para os parâmetros formais diretamente na declaração da função utilizando o operador de atribuição = (ex: def somar(a=0, b=0, c=0):). 
    Se o programa principal chamar a função omitindo algum desses parâmetros, a variável assume o valor padrão estipulado e impede que o script trave por falta de dados.
    
    Escopo Global vs. Escopo Local: 
    Determina o local da memória onde uma variável nasce, vive e morre. Uma variável declarada no programa principal possui escopo global e é visível e acessível em qualquer parte do script. 
    Uma variável declarada ou recebida como parâmetro dentro de uma função possui escopo local, existindo apenas durante a execução daquela rotina específica; tentar acessá-la de fora gera um erro de execução.
    
    A Rasteira do Escopo no Python: 
    Se você declarar uma variável dentro de uma função com o mesmo nome de uma variável global (ex: a = 8 dentro da função, existindo um a = 5 fora), o Python não altera a global. 
    Em vez disso, ele cria uma nova variável local homônima, mantendo a global intacta com o seu valor original.
    
    A Palavra-Chave global: Para modificar diretamente o valor de uma variável global de dentro de uma função, é necessário alertar o interpretador utilizando o comando global seguido do nome da variável (ex: global a) antes de qualquer manipulação. 
    Isso impede a criação de uma variável local e redireciona todas as atribuições seguintes para a estrutura de memória global.
    
    Retorno de Resultados (return): Permite que uma função envie dados de volta para quem a chamou. 
    Ao utilizar a palavra-chave return seguida por uma variável, cálculo ou valor literal, a rotina cessa sua execução e disponibiliza o dado resultante para o programa principal. 
    Esse valor retornado pode ser capturado por uma variável (ex: res = somar(3, 2)), embutido diretamente em prints formatados ou utilizado em validações lógicas. Podem ser retornados números, strings literais, booleanos, listas ou dicionários.

    🔎 Aula 22: Módulos e Pacotes (Lógica e Atribuições do Código):
    O código prático demonstra a transição de um script de arquivo único para uma estrutura modularizada e, posteriormente, para pacotes, detalhando como as atribuições de memória e chamadas funcionam.
    
    Código de Arquivo Único (Fatorial Tradicional):
        Lógica: 
        O script principal solicita uma entrada (num = int(input(...))) e repassa essa variável como parâmetro para a função fatorial(n).
        
        Explicação das Atribuições: 
        Dentro da função, a variável local f = 1 é inicializada com o valor 1 por ser o fator nulo da multiplicação (atribuir 0 zeraria todo o cálculo). O laço for c in range(1, n + 1): utiliza a atribuição composta f *= c (que equivale a f = f * c) para acumular as multiplicações sucessivas. 
        Ao final, o comando return f devolve o valor contido na variável local para a variável fat no programa principal (fat = fatorial(num)).
        
    Separação em Módulo (uteis.py):
        Lógica: 
        Para reduzir o tamanho do arquivo principal (numeros.py), todas as declarações def (fatorial, dobro, triplo) são recortadas e coladas em um arquivo isolado chamado uteis.py.
        
        Explicação das Atribuições: 
        No arquivo principal, a linha import uteis faz com que o interpretador do Python carregue o arquivo vizinho na memória como um objeto de módulo. As atribuições e chamadas deixam de ser diretas e passam a exigir o prefixo do arquivo: fat = uteis.fatorial(num). O interpretador busca a função dentro do escopo do objeto uteis, processa o cálculo e atribui o retorno à variável local do programa principal.
        
    A Relação de Conflito (from ... import):
        Lógica: 
        Ao utilizar a sintaxe alternativa from uteis import fatorial, dobro, as funções são puxadas diretamente para o escopo global do programa principal.
        
        Explicação das Atribuições: 
        Essa abordagem altera a forma como o Python gerencia os nomes na memória. Se o programa principal importar outra biblioteca que também possua uma função chamada dobro, a última importação lida pelo interpretador irá sobrescrever a atribuição anterior na tabela de símbolos do sistema. 
        Por isso, a atribuição via prefixo (uteis.dobro) é defendida como a mais segura.
        
    Evolução para Pacotes (Pastas e Escopo):
        Lógica: Quando o módulo uteis acumula funções demais, ele é transformado em um pacote (uma pasta física chamada uteis). Dentro dela, são criadas subpastas (subpacotes) divididas por assunto: numeros, strings, datas e cores.
        
        Explicação das Atribuições: Cada uma dessas subpastas recebe obrigatoriamente um arquivo __init__.py. É dentro deste arquivo específico que o código das funções correspondentes é colado. No programa principal, a atribuição e a importação passam a mapear a árvore de diretórios: from uteis import numeros. Quando o programa executa numeros.fatorial(num), o Python navega para dentro da pasta uteis, acessa a subpasta numeros, lê o arquivo __init__.py contido nela e executa a rotina especificada.
